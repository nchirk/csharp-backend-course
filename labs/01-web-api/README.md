# Контрольная работа: Разработка Web API на ASP.NET Core

## Оценка «3» (Удовлетворительно)

1. Создайте класс модели `Book` со свойствами: `Id` (int), `Title` (string), `Author` (string), `Year` (int).
2. Создайте API-контроллер `BooksController`.
3. Инициализируйте внутри контроллера (или в отдельном сервисе) приватный статический список `private static List<Book>` с 3-4 книгами.
4. Реализуйте два GET-метода:
    
    - `GET /api/books` — возвращает полный список всех книг.
    - `GET /api/books/{id}` — принимает `id` через маршрут, ищет книгу в списке и возвращает её. Если книга не найдена, метод должен возвращать HTTP-статус 404 Not Found.

## Оценка «4» (Хорошо)

Допишите код на «3».

1. Реализуйте метод POST `POST /api/books` для добавления новой книги:
    
    - Данные книги передаются в теле запроса (JSON).
    - Идентификатор (`Id`) для новой книги должен генерироваться автоматически (например, `Max(id) + 1`).
    - Книга добавляется в статический список, а метод возвращает статус 201 Created или 200 OK вместе с созданным объектом.
    
2. Реализуйте метод DELETE `DELETE /api/books/{id}`:
    
    - Удаляет книгу из списка по её `Id`.
    - Если книга для удаления не найдена, возвращает статус 404 Not Found, если удаление прошло успешно — 204 No Content или 200 OK.

3. Продемонстрируйте работу методов в http-файле.

## Оценка «5» (Отлично)

Допишите код на «4».

1. Ограничение маршрута: Для эндпоинта `GET /api/books/{id}` добавьте встроенное ограничение (constraint), чтобы маршрут срабатывал _только_ если `id` является числом (`int`).
2. Параметры фильтрации: Модифицируйте метод `GET /api/books` (получение всех книг). Добавьте в него необязательный параметр строки запроса `author` (Query string):
    
    - Если параметр передан (например, `/api/books?author=Пушкин`), метод должен вернуть только книги этого автора (без учета регистра).
    - Если параметр пустой, возвращается как обычно весь список.
    
3. Частичное обновление (PATCH): Реализуйте метод PATCH `PATCH /api/books/{id}/title` для быстрого изменения **только названия книги**:
    - Метод должен принимать `id` книги в маршруте и новое название (простую строку `string`) из тела запроса.
    - Если книга найдена, её свойство `Title` обновляется в статическом списке, а метод возвращает измененную книгу и статус 200 OK или стутус 204 No Content.
    - Если книга с таким `id` не найдена, метод должен вернуть статус 404 Not Found.

4. Продемонстрируйте работу методов в http-файле.

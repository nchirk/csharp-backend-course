# Практическое задание: «Работа с миграциями, добавление таблицы, изменение таблицы»

Доработать проект `StudentApiWithDB` из лекции, закрепить навыки работы с **Entity Framework Core**: создания сущностей, настройки связей между моделями, реализации CRUD-операций и применения миграций к базе данных.

## Возьмите за основу код лекции
Перейдите на сайт https://download-directory.github.io/. Вставьте в поле ввода ссылку на код с лекции:
```
https://github.com/nchirk/csharp-backend-course/tree/main/lectures/05-ef-core-migrations/src/lecture-demo
```

Разархивируйте приложение. Если не запускается, обновите на .NET 10.

[Как обновить с .NET 9 на .NET 10 в Rider](/info/upgrade-dotnet.md)

Если не получилось собрать проект, позовите преподавателя.

## Задание 1. Добавить направление обучения `StudyProgram`

Делайте по аналогии с сущностями Group и Student из [текста лекции](./README.md).

- Создать класс `StudyProgram` (направление обучения) с полями `Id`, `Name`. Добавить в `AppDbContext`.
- Настроить связь **«один ко многим»** между `StudyProgram` и `Group`: одно направление может включать несколько групп, каждая группа относится к одному направлению.
- Создать `StudyProgramConfiguration`, прописать в явном виде связь по ForeignKey и ограничение на длину строки Name
- Создать и применить миграцию.
- Добавить CRUD-контроллер для работы с направлениями обучения.
- Создать HTTP-файл `studyProgram.http` для проверки запросов к API.

## Задание 2. Доп задание если осталось время: добавить год обучения в `Group`

- Добавить свойство `Year` типа `int` в модель `Group`.
- Допустимые значения: **от 1 до 4 включительно**.
- Обновить методы контроллера групп с учётом нового поля при создании и редактировании записей.

## Миграции и база данных

Не забудьте в обоих заданиях создать миграцию EF Core и применить её к базе данных с помощью графического интерфейса **JetBrains Rider** или встроенного терминала IDE. 

## Ожидаемый результат

- Миграции созданы и применены к базе данных.
- Приложение запускается, CRUD-операции проверены с помощью HTTP-запросов.

# Практическое задание: «Рефакторинг работы с сущностью Student»

**Цель работы:** Закрепить навыки работы с архитектурным паттерном MVC и технологией Razor Pages в ASP.NET Core. Вам предстоит реализовать вывод списка групп по аналогии с тем, как в лекции был разобран вывод студентов.

**Контекст проекта:**

- Все базовые слои уже настроены. Сервис **`GroupService`** и сущность **`Group`** находятся в проекте классов `StudentApi.Data`.
- `GroupService` уже зарегистрирован в DI-контейнере вашего UI-проекта. Вам необходимо работать исключительно на уровне представления (Presentation Layer).

## Задание 1: Реализация на паттерне MVC

Реализуйте вывод списка групп в проекте StudentMVC, используя классический подход Model-View-Controller в веб-приложении.

1. Создание контроллера

- В папке `Controllers` создайте класс **`GroupController.cs`**.
- Внедрите в него зависимость **`GroupService`** через конструктор.
- Создайте асинхронное действие (Action) **`Index()`**.
- Метод должен вызывать соответствующий метод получения данных из `GroupService` (например, `GetGroupsAsync()`) и передавать полученную коллекцию в метод `Return View(groups);`.

2. Создание представления (View)

- В папке `Views` найдите или создайте подпапку **`Group`**.
- Внутри нее создайте Razor-представление **`Index.cshtml`**.
- Подключите модель данных вверху страницы, указав коллекцию групп с помощью директивы `@model`.
- Напишите HTML-разметку по аналогии с разметкой для студентов.

## Задание 2: Реализация на Razor Pages

Реализуйте аналогичный вывод списка групп в проекте StudentRazorPages, используя подход Razor Pages.

1. Создание страницы и модели (Page & PageModel)

- В папке `Pages` создайте новую страницу Razor с именем **`Groups.cshtml`** (файл логики `Groups.cshtml.cs` создастся автоматически).
- Откройте файл **`Groups.cshtml.cs`** и настройте класс `GroupsModel`:
    - Внедрите **`GroupService`** через конструктор.
    - Объявите публичное свойство `Groups` для хранения списка групп, к которому будет обращаться Razor-страница
    - Реализуйте асинхронный метод **`OnGetAsync()`**, внутри которого вызовите `GroupService`, чтобы заполнить свойство `Groups` данными перед рендерингом.

2. Создание разметки Razor Page

- Откройте файл **`Groups.cshtml`**.
- Убедитесь, что вверху страницы указана директива `@model GroupsModel`.
- Используя синтаксис Razor и цикл `@foreach (var group in Model.Groups)`, сформируйте HTML-структуру (список или таблицу) для вывода свойств каждой группы на экран.
